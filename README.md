Браузерная игра в жанре хоррор-выживания. Ты охранник объекта 499 — следи за камерами, управляй ресурсами и не сходи с ума.

## Запуск локально

Требуется любой локальный HTTP-сервер. Например, через Python:

```bash
cd resonance
python -m http.server 5499
```

Затем открой `http://localhost:5499` в браузере.

## Классы

| Класс | Разблокировка | Особенность |
|-------|--------------|-------------|
| Охранник | Сразу | Без бонусов, честный старт |
| Военный | 15 смен за Охранника | Рассудок падает на 20% медленнее |
| Учёный | 15 смен за Военного | Видит аномалии в кадрах (+25 XP) |

## Режимы

- **Кампания** — 15 смен, сюжет, прокачка персонажа
- **Бесконечная** — выживание без ограничений, доступна после прохождения кампании за Охранника
